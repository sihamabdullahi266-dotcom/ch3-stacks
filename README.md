# Stacks in Java — Chapter 3

This folder contains the Java code examples extracted from the Chapter 3
PowerPoint: **Stacks in Java — Fundamentals, Array-Based and Linked Implementations**.

## Files

- `GenericsExample.java` — generic class and type examples.
- `StackExample.java` — Java `Stack`, `push()` and printing.
- `UndoDepositDemo.java` — undoing bank deposits using `Stack`.
- `UndoCourseDemo.java` — undoing course registration using `Stack`.
- `ArrayStackTraceDemo.java` — trace example requiring the lecture's `ArrayStack<T>` class.
- `EmptyCollectionException.java` — custom empty-collection exception.
- `LinkedListTraversal.java` — linked-list traversal example.
- `LinkedStackTraceDemo.java` — trace example requiring `LinkedStack<T>`.
- `UndoDepositLinkedDemo.java` — bank example using `LinkedStack<T>`.
- `UndoCourseLinkedDemo.java` — course example using `LinkedStack<T>`.

## Important

Some PowerPoint slides show the full `ArrayStack` and `LinkedStack`
implementations as diagrams or visual code that was not available as
extractable text. The files that use these classes are therefore examples
that need those class definitions before they can compile.

The snippets are kept based on the lecture material; they have not been
silently replaced with a different implementation.
